# Releases

poietic-meetings is a single deployed Worker, not a versioned package. There are no version numbers, tags or release notes.

Every push to `main` that passes CI deploys `poietic-meetings` to <https://meetings.poietic.tech> (see [.github/workflows/ci.yml](../.github/workflows/ci.yml)). Merging a pull request is the release, so describe user-visible changes in the pull request itself.
